# Frame Folk – Native Android

Frame Folk is being migrated from its HTML photo editor interface to a native Android application.

## Project Details

- App Name: Frame Folk
- Package: com.prabhat.framefolk
- Language: Kotlin
- UI: Jetpack Compose
- Minimum Android: Android 8.0 (API 26)
- Architecture: Native Android

## Development Roadmap

### Phase 1 – Foundation
- Native Android project
- Dark navy and gold interface
- Photo picker
- Editing category navigation

### Phase 2 – Editing Engines
- Light adjustments
- Color adjustments
- HSL mixer
- Color grading
- RGB curves

### Phase 3 – Advanced Editing
- Effects and details
- Local masking
- Crop and transform
- Presets and undo/redo

### Phase 4 – Export
- Full-resolution JPEG export
- Image quality controls
- Preview and export consistency

## Important

The current Phase 1 interface is a foundation only.
Editing controls and JPEG export are not yet connected to real image-processing engines.
